# kawafriends.com

Pre-launch page for Kawa Friends, served by GitHub Pages from `main` (root).

- Standalone site: no shared Swiftian app menu, footer markup or cross-site links (founder 2026-11-11).
- DNS on Cloudflare, DNS only (never proxied), apex A/AAAA to GitHub Pages, `www` CNAME to `thinkswift.github.io`.
- No images until the founder has reviewed them (no favicon yet for the same reason).
- Visits: Cloudflare Web Analytics beacon, added once the site is registered in the Cloudflare dashboard.
